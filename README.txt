SAMEEDA'S PORTFOLIO — HTML + CSS ONLY

Files:
- index.html: portfolio content
- style.css: responsive styling and visual effects

How to open:
1. Extract this ZIP.
2. Open the sameeda-portfolio-fsd folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" (if installed), or open the file in your browser.

Before publishing:
- Replace each project card's GitHub profile link with the exact repository URL when available.
- To use your real photo, replace the S avatar in index.html with an img element and add your photo file to this folder.
- Check your contact links before publishing.

Publish with GitHub Pages:
1. Create a GitHub repository, for example: sameeda-portfolio.
2. Upload index.html, style.css, and README.txt to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published link to appear in the Pages section.
